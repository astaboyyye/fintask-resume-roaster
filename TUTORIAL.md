# Quick check

1. Run `npm run dev` and open the `Local` URL shown in the terminal (usually `http://localhost:3000`, or `http://localhost:3001` if port 3000 is busy).
2. Choose a text-based PDF resume or drop it onto the upload area.
3. Select **Roast my resume**. Feedback appears below the form.
4. Without `GROQ_API_KEY`, the result says **Quick local feedback**. With the key, it says **AI feedback**.
5. Try a non-PDF, an empty PDF, or a file over 5 MB to check validation messages.
